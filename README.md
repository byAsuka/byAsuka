## Projects

**Raymond Layer** — Persistent memory and context for AI assistants.

A workflow for carrying goals, decisions, and source evidence across sessions. I designed the state structure and update rules around authorization, revision checks, and recovery. *Personal deployment.*

**Oasis** — A standalone desktop workspace for learning.

Course materials, bilingual lecture records, notes, and review in a shared course context. My work focuses on product workflows, interaction design, and keeping self-assessment, practice attempts, and revealed solutions distinct. *Prototype in development.*
