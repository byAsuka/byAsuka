# Jinrui Li

**Electrical Engineering at UC Irvine · Perception, learning, and interactive systems**

I build tools around how people gather information, make sense of it, and act. My work starts with practical problems in learning, photography, and interaction, and connects software with physical interfaces.

I'm a first-year Electrical Engineering undergraduate at the University of California, Irvine. I'm interested in how people and intelligent systems form and revise internal models from incomplete information—and how memory and context support that process over time.

## Current work

### Persistent Memory and Context for AI Assistants

*Raymond Layer · System design and workflow validation · Personal deployment*

When an assistant forgets why a decision was made, completed work can reappear as unfinished. I designed a Google Drive-backed workflow that carries goals, decisions, task states, and source evidence across sessions. It separates evidence from inference and specifies authorization, revision checks, read-back verification, and recovery rules for updates. A macOS deployment has been checked through an independent activation test and reads of the canonical store.

### Oasis — AI Workspace for Learning

*Product and interaction design · Standalone desktop prototype · In development*

Oasis grew from my own bilingual classroom needs into a desktop workspace connecting course materials, lecture records, notes, questions, and review. I defined the course workflows and designed separate records for self-assessments, original answers, and revealed solutions, so an explanation cannot erase evidence of an incorrect attempt. An extracted learning-state module passed six offline regression tests covering record separation, stale sources, failed-write recovery, and concurrent updates.

## Earlier projects

- **Aerial reconstruction and 3D Gaussian Splatting.** Captured multi-view aerial imagery and reproduced alignment, training, and rendering. Wrote monitoring and Gaussian-pruning scripts to explore trade-offs among visual detail, frame rate, and GPU memory use.
- **Physical controls for mobile photography.** Iterated from a mechanical dial with actuation-force and hand-obstruction problems to Hall sensing and Bluetooth HID, then explored capacitive rotary input and haptic feedback. Prototype documentation includes sketches, photographs, and partial test records.
- **Interactive Prisoner's Dilemma exhibit.** Designed and wrote the main code for a QR-accessible strategy game used by judges at Duke Math Meet China 2024, alongside posters and slides. Our team received the **Best Visual Design Prize**.
